## 3 Test entries

Window rule: rows from the **last** `rustTester.Marker(id=START)` row that precedes the first `rustTester.Marker(id=END)` row following it, through that END row plus the END `rustTester.MARK` command's own `cmdDisp` rows (at most two), inclusive; ordering key `t = epoch·1e6 + fsw`, archive index on ties. Channel rows are those with `t` between the first and last window event. `commands_sent` = commands from the matching START sending (its last sending if re-sent) through the END sending, inclusive.

Standard `complete` block (STD): both markers present; RustReference samples >= 2.
Standard absence block (ABS): event cmdDisp.MalformedCommand count == 0; event cmdDisp.InvalidCommand count == 0; event cmdDisp.TooManyCommands count == 0.
Packets (named channel sets for `<packet> samples >= n`): RustReference = rustCounter.Counter, rustCounter.TickCount, rustMonitor.RunCount, rustMonitor.Limit, rustCounter.ThresholdValid; RustTesterBurst = rustTester.BurstResponsesOk, rustTester.BurstResponsesError.
